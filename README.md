# Расстояния по Восточно-Казахстанской области

Статический сайт для расчёта автомобильных расстояний от центра Усть-Каменогорска до сёл и других населённых пунктов Восточно-Казахстанской области.

## Возможности

- Карта OpenStreetMap без API-ключа.
- Поиск населённых пунктов через Photon.
- Автомобильный маршрут и расстояние через OSRM.
- Импорт Excel и CSV, ручное добавление пунктов.
- Экспорт отчёта Excel.

## Публикация через GitHub Pages

1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите в корень репозитория файлы `index.html` и `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Укажите ветку `main` и папку `/(root)`, затем нажмите **Save**.
6. После публикации GitHub покажет ссылку на сайт в том же разделе **Pages**.

## Использование

Откройте опубликованный сайт, нажмите **«Загрузить карту»**, затем загрузите таблицу с колонками **«Район»** и **«Село»** или добавьте пункты вручную. Нажмите **«Рассчитать расстояния»** и скачайте Excel-отчёт.

Для ручного расстояния при импорте можно заполнить колонку **«Расстояние, км»**.

## Данные и доступность

Для показа карты и расчёта требуется интернет-соединение. Сайт обращается к публичным сервисам Photon, OSRM и OpenStreetMap. У этих сервисов могут быть ограничения по частоте запросов и доступности; они не гарантируют бесперебойную работу. Результат геопоиска следует сверять на карте, особенно если названия населённых пунктов совпадают.
